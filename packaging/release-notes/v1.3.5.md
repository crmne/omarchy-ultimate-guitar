A privacy fix: other users on the same machine can no longer see which song you are looking up. Nothing changes in how the reader looks or works.

**Install** with `omarchy plugin add https://github.com/crmne/omarchy-ultimate-guitar.git --enable --yes`, or update an existing install with `omarchy plugin update crmne.ultimate-guitar --yes`.

## Fixed

- **The song you are playing stays private to you.** The fetch helper used to receive the search (artist and title) and the tab address, which names the song, as command-line arguments, and every user on the machine can read those from the process list. They now travel in the helper's environment, which only you can read, and its command line carries only fixed words. Found while preparing the plugin for marketplace review. By @crmne.
- **A stalled lookup gives up instead of hanging.** Each lookup now has one overall deadline of 45 seconds on top of the per-read network timeouts, so a server that trickles a response slowly cannot keep it waiting. When it fires, the reader says Ultimate Guitar took too long to answer, and the refresh button tries again. By @crmne.
